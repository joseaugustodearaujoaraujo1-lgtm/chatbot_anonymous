<h1>🔐 Anonymous Chatbot</h1>
<h3>Privacidade por design. Responsabilidade por princípio.</h3>
<p>Chatbot de IA com cadastro anônimo, autenticação por código e histórico protegido.</p>
</div>
<h2>1. Projeto</h2>
<p>O sistema permite criar uma conta sem dados pessoais, conversar com um agente de IA e consultar conversas anteriores.</p>
<p><strong>Tecnologias:</strong> Next.js, React, JavaScript, CSS Modules, Axios, Three.js, GSAP, Node.js, Express, MySQL, JWT e n8n.</p>
<h2>2. Como executar</h2>
<p><strong>Backend:</strong> entre em <code>servidor</code>, execute <code>npm install</code>, copie <code>.env.example</code> para <code>.env</code> e execute <code>npm run dev</code>.</p>
<p><strong>Banco:</strong> execute <code>mysql -u root -p &lt; schema.sql</code> ou abra <code>servidor/schema.sql</code> no MySQL Workbench.</p>
<p><strong>Frontend:</strong> entre em <code>front-end</code>, execute <code>npm install</code>, configure o <code>.env</code> e execute <code>npm run dev</code>.</p>
<h2>3. Experiência</h2>
<p>Interface responsiva com terminal futurista, GIF animado e cadeado 3D feito com Three.js e GSAP para representar tecnologia, segurança e privacidade.</p>
