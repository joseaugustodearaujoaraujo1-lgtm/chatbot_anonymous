## 1. Projeto
O sistema permite criar uma conta sem dados pessoais, conversar com um agente de IA e consultar conversas anteriores.
**Tecnologias:** Next.js, React, JavaScript, CSS Modules, Axios, Three.js, GSAP, Node.js, Express, MySQL, JWT e n8n.
## 2. Como executar
**Backend:** entre em `servidor`, execute `npm install`, copie `.env.example` para `.env` e inicie com `npm run dev`.
**Banco:** execute `mysql -u root -p < schema.sql` ou abra `servidor/schema.sql` no MySQL Workbench.
**Frontend:** entre em `front-end`, execute `npm install`, configure o `.env` e inicie com `npm run dev`.
